## 2. Как решаем и записываем

**Роли** (рекомендация, решается в D0):

- код и правила времени — последнее слово у друга;
- вид, интерфейс, страница itch, позже магазин — у Бориса;
- концепт, объём и деньги — вдвоём;
- спор не тянем: решает владелец области и записывает причину.

**Где что лежит:**

| Что | Где | Кто пишет |
|---|---|---|
| Исследования и предложения | `boris/` | чат Бориса |
| Очередь вопросов и их статус | `boris/decisions.md` | чат Бориса или чат по плану по просьбе |
| Принятые решения с причинами | `docs/history.md` | чат по плану |
| Правила игры, план, задачи | `docs/concept.md`, `docs/roadmap.md`, `docs/progress.md` | чат по плану |
| Все версии файлов | git и pull requests | само |

**Правила записи:**

- одно решение — одна запись: дата, что решили, почему, какие варианты отвергли, кто решил, какие файлы меняются;
- старое не переписываем: передумали — пишем новое решение «отменяет D3 от 9.11» с причиной, так видна вся история;
- каждое изменение попадает в репозиторий через pull request, поэтому к любой версии можно вернуться.

**Как откатиться:** найти решение в `docs/history.md` → по дате найти его pull request → попросить любой чат вернуть файлы из этого pull request и записать «отменяет …».

**Деньги, страна, договорённости** — только в чате, не в репозитории: он открытый.

**Работа Бориса над игрой** (картинка, интерфейс, карточки уровней) идёт через обычные чаты по плану, как у друга: задачи берутся из `docs/roadmap.md`. Папка `boris/` — только для исследований и предложений. Двое никогда не правят один уровень одновременно.
