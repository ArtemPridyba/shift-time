# Экономия токенов, навыки и перестройка репозитория (8.11.2026)

Предложение Claude, **не решение**. Вопросы к команде — D40, D41, D43 в [decisions.md](decisions.md). Как делится работа между моделями — [plan.md](plan.md).

## 1. Что уже есть

- Навык `razbor` в `.claude/skills/` (перенесён из testone): раскладывает несколько задач одного сообщения по моделям и помощникам, показывает таблицу и ждёт «ок».
- Помощники `helper` (Sonnet) и `reader` (Haiku) в `.claude/agents/`.
- Правила «Spend few tokens» в корневом `CLAUDE.md` и таблица моделей в `docs/how-we-work.md`.

Чего не хватает: всё это срабатывает, только если чат сам вспомнит. Нет меток моделей у задач, нет проверки «я на той ли модели», нет учёта двух подписок, а `razbor` советует усилия max, которых у линии О нет.

## 2. Чтобы само применялось

Три слоя, от дешёвого к дорогому (выбор — D41):

1. **Метка модели в каждой карточке задачи** `docs/roadmap.md`: «Модель: О / О+ / С / С− / Г / Л» (значения — в [plan.md](plan.md)). Человек берёт задачу своей линии, чат берёт метку из карточки.
2. **Проверка модели в начале чата.** Первый шаг: Claude смотрит, на какой модели он запущен (в облачной сессии — по данным сессии), и сверяет с меткой. Не совпало — говорит об этом и даёт первое сообщение для нужной модели, работу не начинает, пока человек не скажет «всё равно делай».
3. **Хук начала чата** (по желанию): скрипт сам печатает «Сейчас» из `docs/progress.md` и состояние ветки. Экономит 2–3 шага в каждом чате, а каждый шаг перечитывает весь разговор.

Хук на каждое сообщение («напомни про экономию») не советую: он сам тратит токены на каждом шаге.

**Правки `razbor`:** корзина «Opus» в чате на Sonnet превращается в «новый чат линии О» с готовым первым сообщением; max заменяется на xhigh; помощник на Opus — только из чата на Opus.

## 3. Голосовой ввод: навык `golos`

Навык из другого проекта не нашёлся: в testone есть только `razbor`, zmeinda пустой, среди навыков аккаунта его нет (D40). Если не найдём, предлагаю свой.

**Когда срабатывает:** длинное сообщение без структуры, с «что ещё», «вот», «короче», повторами, либо человек пишет «голос» или `/golos`.

**Что делает:**

1. **Чистит:** убирает слова-паразиты, исправляет слова, которые распознавание путает, по словарю `glossary.md` рядом с навыком.
2. **Пересказывает задачей:** цель одной фразой; задачи по пунктам, у каждой — признак готовности; решения и ограничения из сообщения; что непонятно.
3. **Сверяет:** каждая фраза оригинала попала в пункт или помечена как «вода»; ничего не потеряно и не добавлено от себя. Пропущенное — в отдельной строке.
4. **Ждёт «ок»** только если в пересказе есть решение команды или неясность. Иначе показывает пересказ в 3–5 строках и работает.

**Начало словаря** (дополняется по ходу):

| Слышится | Значит |
|---|---|
| аргон, Gemini-аргон | Gemini 4 Argon |
| шифт | Shift |
| годо, годот | Godot |
| опус, сонет, хайку | Opus, Sonnet, Haiku |
| эффорт, хай, медиум, икс хай | effort: high, medium, xhigh |
| итч, ичио | itch.io |
| пул реквест, пиар | pull request |
| антигравити | Antigravity |
| скилл, разбор | навык, `razbor` |
| ворота | ворота недели из `docs/roadmap.md` |

Навык стоит положить и в навыки аккаунта claude.ai: тогда он работает и в обычном чате, без Claude Code.

## 4. Экономия в чатах

Есть и работает — оставить:

- одна задача — один чат; после PR — новый чат;
- читать только нужные строки, `grep -n` сначала;
- короткая команда тестов;
- длинные логи читает `reader`;
- не следить за PR;
- раз в неделю записывать цену чатов.

Добавить:

- **метки моделей и проверка модели** (раздел 2);
- **короче корневой `CLAUDE.md`:** его перечитывает каждый шаг каждого чата. «Visual rules» после выбора стиля переедут в `docs/setting.md`, в `CLAUDE.md` останется ссылка;
- **длинное чтение — в Gemini:** видео, большие документы, второе мнение. У Gemini большое окно, а лимит Claude не тратится;
- **голос через `golos`:** переделка после непонятого сообщения — самая дорогая трата;
- **усилия:** О — high, О+ — xhigh только для кода во многих файлах, max не используем;
- **длина чата:** больше 30–40 шагов — признак, что задача велика: передача в «Сейчас» и новый чат.
