---
description: Start a Shift Time task — read the state, take a task, plan
---

1. Run `git checkout main` and `git pull`.
2. Read the «Сейчас» section of `docs/progress.md`.
3. Take the task the user named, or the next task in «Дальше» with the label А or А− that nobody has in «Кто что делает». Say which one you took.
4. Read only that task's section of `docs/roadmap.md` and the files it lists. Read the rules in `AGENTS.md` and, before changing code, the sections of `CLAUDE.md` it names.
5. Create the branch `ag/<task>-<short-name>`.
6. Write a plan in 3–5 lines in Russian. If the task changes what the player sees or the rules of time, say what the player will see and what you need to ask, and wait for «ок».
