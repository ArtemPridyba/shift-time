# Звук (D183)

Звуки игры синтезирует код, чужих файлов нет: `tools/audio/make_sounds.py` делает из шума,
синусоид и фильтров около 40 звуков в `game/assets/audio/` (OGG, моно). У звуков мира есть
обратный двойник `<имя>_rev.ogg` — его игра включает под Shift.

- **Пересоздать звуки:** `pip install numpy scipy soundfile pillow` (один раз), потом
  `python3 tools/audio/make_sounds.py` — все, или `... make_sounds.py door_stop spark` — только эти;
  `--sheet build/audio/sheet.png` рисует спектрограммы, `--list` печатает список. Затем
  `godot --headless --path game --import`.
- **Громкость и правила:** `game/data/audio.json`. `sounds.<имя>.db` — громкость поверх файла;
  `objects` — какое поле записанного состояния какого класса какой звук даёт (виды `move`, `flag`,
  `set`, `change`, `reach`, `while` описаны в `_about`). Проверка данных ловит неизвестные звуки
  и отсутствующие файлы.
- **Как устроено:** автозагрузка `Sound` (`autoload/sound.gd`) ставит рядом с каждым `RoomTime`
  узел `RoomSound` (`audio/room_sound.gd`). Тот каждый тик читает кадр под курсором и включает
  звуки по изменениям полей. Под Shift изменение — это записанное прошлое задом наперёд, поэтому
  звучит обратный двойник, и начинается он заранее, по кадрам впереди курсора: удар приходится
  ровно на кадр события. Действие героини под Shift звучит вперёд. `Sound` ещё играет петлю
  перемотки, гул цеха (под Shift — его обратный двойник), клики меню и звук выхода;
  `TimeSound` (`audio/time_sound.gd`) — два звука нажатия и отпускания Shift, пути в
  `data/time_hud.json`.
- Только громкость, высота и положение на шине Master: эффекты шин в веб-сборке не играют.
- Каждый файл — строка в `docs/art/log.md`.
