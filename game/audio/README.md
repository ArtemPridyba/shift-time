# Звук времени (место под него)

Задача 1.5 оставила звук на потом. Здесь лягут два файла: обычный ход и обратный ход
(обратная огибающая, [setting.md](../../docs/setting.md), раздел 4).

Как подключить: положить файл сюда и вписать путь в `game/data/time_hud.json`,
раздел `audio`, поля `forward` и `rewind`, например `"rewind": "res://audio/time_rewind.ogg"`.
Код уже готов: `time_sound.gd` играет нужный звук при смене направления, а пустой путь
ничего не играет. Проверка данных ловит путь к несуществующему файлу.

Каждый файл получает строку в `docs/art/log.md` (сервис, запрос, лицензия): репозиторий
публичный, а после джема игру продают, поэтому нужны только источники с коммерческой лицензией.
