# Карточки уровней

Черновики Claude от 5.11.2026 по [concept.md](../concept.md) и [architecture.md](../architecture.md); карточки 08–10 — Артём, 12.11; карточки 01–07 выправлены 13.11.2026 под правило «А» и решения до 13.11 (задача 2.4). Решения нужно проверить в блокауте и переписать после плейтеста. Шаблон — [_template.md](_template.md).

## Правила для всех уровней

- Каждый уровень вводит **одно новое правило** и проверяет его в новой ситуации.
- Решение не зависит от угадывания тайминга: все окна действия не короче 3 с, а где можно, мир закреплён на начале истории, пока зажат Shift (основной приём).
- **Правило «А»:** отпущенный Shift ничего не стирает, мир повторяет записанное. Прошлое меняет только вмешательство под Shift: запись правее него отбрасывается, и мир идёт заново. В каждой карточке есть раздел «Если отпустить Shift».
- Комната — один экран 16:9. Длинный уровень — несколько комнат подряд, у каждой своя история.
- Всё движение в комнате конечное: дверь закрылась и стоит, платформа уехала и стоит. Бесконечный цикл дал бы пройти уровень без Shift, просто дождавшись. У каждого уровня есть тест «без Shift не пройти».
- Начало истории не должно теряться, пока игрок думает: история хранит 20 с, а предыстория уже занимает её часть. Как это решить — вопрос D56 в [decisions.md](../decisions.md).
- В уровнях про вмешательство (04, 06) проход при зажатом Shift по миру, стоящему на начале истории, не должен вести к выходу — вопрос D57.
- Уровни со «следствием» используют **предысторию** (`prelude_seconds`): игрок появляется, когда часть событий уже произошла, и может откатить мир и увидеть причину.
- У каждого уровня есть тест решения `game/tests/solutions/level_NN.json`.
- Неверная попытка должна быть видимо бесполезной (ничего не ломается безвозвратно): игрок откатывает мир и пробует снова. Сброс комнаты по `R` есть всегда. Исключений два: огонь — игрок, простоявший в огне 3 секунды, гибнет (решение 8.11.2026), и вода — под водой дыхание кончается за 5 с (D50). В обоих случаях комната сбрасывается; опасные зоны видны заранее.
- Числа времени ниже — стартовые, они живут в `game/data/levels.json` и в данных объектов.
