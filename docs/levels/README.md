# Карточки уровней

Черновики Claude от 5.11.2026 по [concept.md](../concept.md) и [architecture.md](../architecture.md). Карточки — отправная точка для задачи 2.4 и самих уровней: решения нужно проверить в блокауте и переписать после плейтеста. Шаблон — [_template.md](_template.md).

## Правила для всех уровней

- Каждый уровень вводит **одно новое правило** и проверяет его в новой ситуации.
- Решение не зависит от угадывания тайминга: все окна действия не короче 3 с, а где можно, мир закреплён на начале истории, пока зажат Shift (основной приём).
- Уровни со «следствием» используют **предысторию** (`prelude_seconds`): игрок появляется, когда часть событий уже произошла, и может откатить мир и увидеть причину.
- У каждого уровня есть тест решения `game/tests/solutions/level_NN.json`.
- Неверная попытка должна быть видимо бесполезной (ничего не ломается безвозвратно): игрок откатывает мир и пробует снова. Сброс комнаты по `R` есть всегда. Единственное исключение — огонь: игрок, простоявший в огне 3 секунды, гибнет, и комната сбрасывается (решение 8.11.2026); опасные зоны видны заранее.
- Числа времени ниже — стартовые, они живут в `game/data/levels.json` и в данных объектов.

## Порядок прохождения (решение команды 8.11.2026)

Номера карточек не меняем, чтобы не ломать ссылки; порядок в игре такой:

| Позиция | Карточка | Название |
| :-: | :-: | --- |
| 1 | 01 | Следствие |
| 2 | 02 | Поток |
| 3 | 03 | Платформа |
| 4 | 04 | Вмешательство |
| 5 | 08 | Дерево и огонь |
| 6 | 09 | Тьма и лампа |
| 7 | 10 | Обратные предметы |
| 8 | 05 | Предмет и траектория |
| 9 | 06 | Причина и следствие |
| 10 | 07 | Финальная комбинация |

При урезании (05, затем 10) уровней остаётся 8, что выше нижней границы в 7. «Следствие» и «Предыстория» у карточек 08–10 пока не заполнены: их назначит карточка при задаче 2.4.
