## 7. Проверка на itch до публикации

1. **Save & view page** (черновик видно по ссылке только вам).
2. **Run game** → клик в игру → меню, Start, Shift, R, Esc, полный экран (кнопка в углу кадра), звук.
3. **Прогон главы на itch автоматом:** в Firefox правой кнопкой по игре → «Этот фрейм» → «Открыть фрейм в новой вкладке»; в Chrome — правой кнопкой → «Просмотреть код», найти тег `iframe` и скопировать его адрес `https://html.itch.zone/...`, дописать к адресу `?solution=chapter` (если в адресе уже есть `?`, то `&solution=chapter`) и открыть. Игра сама пройдёт все пять уровней; итог — в консоли браузера (F12 → Console), строки `SOLUTION level_01: exit at tick …` и `SOLUTION done: 5 of 5 levels reached the exit`. На компьютере с видеокартой это около 3 минут. Без `?solution=` игра обычная.
4. Если всё хорошо: **Edit game → Visibility & access → Public → Save**.

## Если что-то пошло не так

- **Чёрный экран или «loading» без конца:** в консоли браузера (F12) ошибка — скопировать её в сессию. Чаще всего в архиве `index.html` не в корне: пересобрать zip из содержимого папки, а не из самой папки.
- **Нет звука:** кликнуть в игру (браузер включает звук только после нажатия); проверить громкость в паузе (Esc).
- **Игра не ловит клавиши:** кликнуть в кадр игры один раз.
- **Не тот размер кадра:** Edit game → Embed options → Viewport 1280 × 720.
