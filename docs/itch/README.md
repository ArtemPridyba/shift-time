## Проверка веб-сборки в браузере

`node tools/web_check.js` — открывает `build/web` в Chromium (Playwright), проходит меню → «Levels» → каждый уровень: Shift на 3 с, отпустить, R, Esc → «Levels». Пишет в `build/web_check/` снимок каждого шага, консоль страницы (`console.txt`) и отчёт (`report.txt`: вес файлов, время до меню, кадры в секунду). Сначала собрать веб-сборку командой «Web export» из `CLAUDE.md`.

## Прогон главы в браузере (D203)

Игра сама проходит уровни по `game/tests/solutions/level_NN.json`, жмёт клавиши по тикам физики — поэтому при любом числе кадров в секунду проходит так же, как тест, только медленнее. Без параметра игра обычная.

- **В браузере:** `index.html?solution=chapter` — все уровни подряд, как игрок: уровень пройден — переход в следующий; `?solution=level_03` — один; `?solution=level_01,level_03` — эти. Итог — в консоли (`SOLUTION level_01: exit at tick 1053`, в конце `SOLUTION done: 5 of 5 levels reached the exit`) и в `window.solutionReplay`. Сохранение прогресса не трогается.
- **В редакторе:** Project → Project Settings → Run → Main Run Args: `-- --solution chapter`, F5. Из консоли: `godot --path game -- --solution chapter`.
- **Автоматом в Chromium:** `node tools/web_check.js --solution chapter --timeout 4000` — ждёт итога, снимок экрана раз в `--every` секунд, отчёт в `build/web_check/report.txt`; код выхода 0, если все уровни дошли до выхода.
- Решения лежат в сборке (`include_filter` пресета Web, 19 файлов, несколько КБ); остальные `tests/` в сборку не идут.

Итог 27.11 (ветка `claude/itch-solution-replay`, Chromium без видеокарты; первый прогон без звука в окне 1280×720, второй — после слияния звука №116 и подсказок №114, в окне 960×540):
