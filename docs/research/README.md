Папка `boris/`, где они лежали, закрыта 8.11.2026; полная версия — в истории git (коммит `709122c`). Ссылки внутри файлов на `boris/` и первые сообщения «Сессия Бориса» устарели.

- [analysis.md](analysis.md) — первый разбор (6.11): концепт, аналоги, правила джема (сдача 1.12, 21:37 UTC; категории; публичный репозиторий; вопрос про ИИ при сдаче), советы участников (веб-сборка сразу, запасная клавиша для Shift из-за залипания клавиш в Windows).

- [mechanics.md](mechanics.md) — 12 приёмов похожих игр под наши правила, проверено по страницам 26 игр (7.11). Пригодится для карточек уровней (задача 2.4).
