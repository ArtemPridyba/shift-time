## Известные проблемы

- Затемнение (2.8) в headless-тестах не рисуется: шейдер `game/ui/darkness.gdshader` нужно посмотреть глазами в редакторе и в веб-сборке (положение дыр при движении камеры, просадки).
- Дверь в тестовой комнате ходит сама по циклу из `objects.json`, пока нет кнопок (2.1); потом её поведение заменит кнопка.
- Мир ждёт целиком, если один объект задавил бы игрока (2.3): пока герой стоит под закрывающейся дверью, стоит и платформа.
- Надпись направления времени в тестовой комнате временная: её заменит индикатор на устройстве (1.5).
- История 20 секунд для всех комнат (`history_seconds` в `game/data/time.json`): дальше откатить нельзя, мир остаётся таким, каким стал.
- Тестовая комната шире экрана (40×17 клеток, камера за игроком), а уровни по решению 8.11 — на один экран: учесть в 2.5.
- Срок плотный: 10 уровней за три недели. Следить за воротами недели 2 и резать по списку урезания.
- У Артёма Antigravity не показал `/start` и `/finish`; по поисковой выдаче 9.11 официальный путь — `.agents/workflows/`, как у нас. Возможная причина — чат вне проекта: команды из папки проекта видны только в чате внутри проекта. Работают запасные сообщения из [how-we-work.md](how-we-work.md). Не проверены по официальным страницам: лимиты Nano Banana Pro, Veo и Antigravity в подписке AI Pro.
- Без `gh` агент Antigravity только пушит ветку: PR открывает человек.
