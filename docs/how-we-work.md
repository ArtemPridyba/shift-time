# Как мы работаем

Памятка для двоих. ИИ не помнит прошлые чаты: память проекта — файлы в репозитории. Одна задача — один чат — одна ветка — один pull request (PR).

## Главное

1. **Права равные.** Вопрос, который надо решить, — строка в [decisions.md](decisions.md) и сообщение в общем чате. Отвечает тот, кто первым взялся; передумали — новое решение «отменяет …», старое не стираем.
2. **Задачу берёт тот, у кого подходящий инструмент** — метка в карточке задачи в [roadmap.md](roadmap.md). Claude Code — только О и О+; всё остальное — Antigravity и приложение Gemini.
3. **Перед началом впишите себя** в «Кто что делает» в [progress.md](progress.md) и напишите в общий чат. Двое никогда не правят одну сцену уровня одновременно.
4. **Задачи, которые меняют правила времени или то, что видит игрок, — сначала план** и ваше «ок».
5. **Чат кончается на PR.** Сливайте PR до следующего чата, иначе новый чат этой работы не увидит.
6. **Срок горит — режем по списку урезания** из [roadmap.md](roadmap.md), а не придумываем на ходу.

## Инструменты

| Инструмент | У кого | Для чего | Лимиты |
|---|---|---|---|
| Claude Code (облако, claude.ai/code) | у одного | метки О и О+: ядро времени, первые образцы, самые сложные уровни | короткие — берегите |
| Antigravity (программа на компьютере) | у обоих | метки А и А−, иногда О (Claude Opus внутри Antigravity) | квота Google: у Gemini сброс каждые 5 часов, у Claude в Antigravity — раз в неделю, и тратится она быстрее (по обзорам) |
| Приложение Gemini (gemini.google.com) | у обоих | метка Г: картинки (Nano Banana Pro), видео (Veo), музыка (Lyria 3 Pro), второе мнение, разбор видео плейтеста | дневные лимиты подписки |
| Обычный чат Claude | у обоих | вопросы и тексты без репозитория | бесплатный план — только чат |

## Метки задач

| Метка | Модель | Где |
|---|---|---|
| О | Opus, усилия high | Claude Code или Opus в Antigravity |
| О+ | Opus, усилия xhigh | Claude Code |
| А | Gemini 4 Argon (запасной — Claude Sonnet в Antigravity) | Antigravity |
| А− | Gemini: документы, карточки, данные | Antigravity или приложение Gemini |
| Г | Gemini: картинки, видео, музыка, второе мнение, видео плейтеста | приложение Gemini |
| Л | люди | — |

- Усилия max не используем: Claude дольше думает и чаще передумывает.
- Чат сам сверяет свою модель с меткой задачи. Не совпало — скажет и даст первое сообщение для нужного инструмента.
- Gemini не справился с задачей А за один чат — задача переходит на О, а в [decisions.md](decisions.md) появляется вопрос, что ещё отдавать Gemini (D45).

## Настройка (один раз)

### Antigravity

1. Скачайте Antigravity с официального сайта Google и войдите тем аккаунтом Google, где подписка AI Pro.
2. Склонируйте репозиторий через GitHub Desktop и поставьте Godot 4.7.2 ([README](../README.md), «Как запустить на компьютере»). Положите Godot в `C:\Godot\` — там его найдёт `run_tests.bat` — или пропишите путь в переменной `GODOT`.
3. В Antigravity откройте папку репозитория (File → Open Folder).
4. Модель агента — Gemini 4 Argon; если её нет в списке, самая сильная Gemini. Для задач О — Claude Opus.
5. Запуск команд в терминале в первые дни — с подтверждением; когда освоитесь, разрешите `git` и `godot` без вопросов.
6. Проверка: спросите агента «Какие правила проекта ты видишь?» — он должен назвать `AGENTS.md`. Наберите `/` — в списке должны быть `/start` и `/finish`. Если их нет, переименуйте папку `.agents` в `.agent`: официальная страница из облака не открылась, путь взят из обзоров.
7. Git: имя и почта, вход в GitHub (через GitHub Desktop или `gh auth login`), чтобы агент мог пушить ветки. PR можно открыть на сайте GitHub.

### Claude Code (облако)

Ничего настраивать не нужно: хук начала сессии сам печатает «Сейчас» из [progress.md](progress.md), а в облаке ставит Godot и импортирует проект. Модель и усилия выбираются в приложении: Opus, high; xhigh — только для О+.

### Приложение Gemini

Заведите три Gem (свои помощники с инструкцией и файлами), чтобы не вставлять инструкцию каждый раз:

- **«Shift Time — арт»:** лист стиля и общий фрагмент запроса (после К2), до него — запросы из [style.md](style.md).
- **«Shift Time — проверка уровней»:** правила из [concept.md](concept.md) и шаблон карточки. Задача: найти угадывание тайминга, второе новое правило на уровне, решение, которое не работает с кадра 0.
- **«Shift Time — плейтест»:** разбор видео прохождения по таймкодам: где игрок застрял, что понял неверно.

## Первое сообщение

### Antigravity

```text
/start
```

Нужна конкретная задача — `/start 2.1`. Если команды нет:

```text
Это проект Shift Time. Работай по AGENTS.md. Прочитай «Сейчас» в docs/progress.md, возьми следующую задачу с меткой А и напиши план. Жди моего «ок».
```

### Claude Code

```text
Это проект Shift Time. Возьми следующую задачу с меткой О из «Дальше».
Напиши план: что увидит игрок, что решишь сам, вопросы. Жди моего «ок».
```

«Сейчас» Claude видит сам: его печатает хук. Нужна другая задача — «возьми задачу 2.3».

### Другие шаблоны (для обоих)

Уровень по карточке:

```text
Это проект Shift Time. Задача 3.1: собери сцену уровня и тест решения по карточке из docs/levels/. Сначала план в 3–5 строк, жди «ок».
```

Отзыв на задачу, PR которой слит:

```text
Это проект Shift Time. Отзыв на задачу <номер>:
1. <главное>
2. <остальное>
Поправь, потом тесты и PR.
```

Вопрос без изменений:

```text
Это проект Shift Time. Ничего не меняй. Объясни, как устроена запись истории.
```

Конфликт в PR («This branch has conflicts»):

```text
Это проект Shift Time. Реши конфликт в PR №<номер>: оставь изменения обеих сторон.
```

Несколько разных задач в одном сообщении — Claude Code раскладывает их навыком `razbor` (или напишите `/razbor`), Antigravity — по тому же файлу.

## Конец задачи

Напишите «заканчиваем» (Claude Code) или `/finish` (Antigravity). Чат:

1. запускает оба теста — они зелёные;
2. обновляет «Сейчас» в [progress.md](progress.md) и убирает себя из «Кто что делает»; пишет журнал и решения в [history.md](history.md);
3. делает коммит, пуш и PR с описанием по-русски: что изменилось и как проверить;
4. последним сообщением даёт следующую задачу и первое сообщение для неё.

Слейте PR, когда проверка «Tests» внизу его страницы зелёная: Merge pull request → Confirm merge. Красная — новый чат: «почини проверку в PR №…». Сломалось после слияния — кнопка Revert на странице слитого PR вернёт всё как было. Незаконченную задачу тоже сливайте: в «Сейчас» будет передача, и следующий чат продолжит с неё.

## Как не мешать друг другу

- Перед началом — свежий `main` (в GitHub Desktop: Fetch, потом Pull); строка в «Кто что делает»; сообщение в общем чате.
- Задачи с разными файлами (поле «Файлы» в карточке). Уровни — каждый в своей сцене.
- После слияния напишите второму, чтобы он подтянул `main`. Чем дольше PR висит, тем вероятнее конфликт в `progress.md` и `history.md`.

## Голосовой ввод

Диктуйте как удобно. Claude Code применяет навык `golos`: убирает лишние слова, исправляет ошибки распознавания по словарю `.claude/skills/golos/glossary.md`, пересказывает задачу по пунктам и сверяет пересказ с оригиналом. «Ок» он спрашивает, только когда есть решение или неясность. Antigravity делает то же по `AGENTS.md`. Слово распозналось неверно — попросите добавить строку в словарь.

## Экономия

- Новый чат после PR и после часа тишины: каждый шаг перечитывает весь разговор, длинный чат дорожает.
- Opus — high; xhigh — только для О+.
- Длинное чтение (видео, большие документы, второе мнение) — в приложение Gemini; в Claude приносите короткий итог.
- Большие задачи начинайте сразу после сброса лимита, мелкие — в конце окна.
- Раз в неделю попросите любой чат Claude Code: «Запиши цену прошлых чатов» — он впишет цену в журнал [history.md](history.md).

## Отзыв

- Поиграйте 5 минут, потом напишите всё одним сообщением: сначала то, что мешает играть, потом мелочи, потом идеи.
- Просите конкретное: не «сделай загадку интереснее», а «в уровне 03 платформа должна ждать на верхней точке на секунду дольше».
- Чат пошёл не туда — остановите сразу и поправьте.
- Новая идея посреди задачи — в «Идеи на потом» в [roadmap.md](roadmap.md), а не в код.

## Плейтест

В неделе 3 дайте 2–3 людям пройти уровни без объяснений и запишите экран. Не подсказывайте, смотрите, где застряли. Запись отдайте Gem «плейтест», итог — в `docs/playtest.md`: уровень, где остановились, что поняли неверно, что сказали. Это самый ценный материал недели 4.
