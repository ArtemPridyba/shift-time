# Как мы работаем

Памятка для двоих. ИИ не помнит прошлые чаты: память проекта — файлы в репозитории. Одна задача — один чат — одна ветка — один pull request (PR).

## Главное

1. **Права равные.** Вопрос, который надо решить, — строка в [decisions.md](decisions.md) и сообщение в общем чате. Отвечает тот, кто первым взялся; передумали — новое решение «отменяет …», старое не стираем.
2. **Задачу берёт тот, у кого подходящий инструмент** — метка в карточке задачи в [roadmap.md](roadmap.md). Claude Code на Opus — только О и О+, на Sonnet — ещё и А; всё остальное — Antigravity и приложение Gemini. Метки от тарифа не зависят: задачу А делает та модель, что есть у человека (D46).
3. **Перед началом впишите себя** в «Кто что делает» в [progress.md](progress.md) и напишите в общий чат. Двое никогда не правят одну сцену уровня одновременно.
4. **Задачи, которые меняют правила времени или то, что видит игрок, — сначала план** и ваше «ок».
5. **Чат кончается на PR.** Сливайте PR до следующего чата, иначе новый чат этой работы не увидит.
6. **Срок горит — режем по списку урезания** из [roadmap.md](roadmap.md), а не придумываем на ходу.

## Метки задач

| Метка | Модель | Где |
|---|---|---|
| О | Opus, усилия high | Claude Code или Opus в Antigravity |
| О+ | Opus, усилия xhigh | Claude Code |
| А | Gemini 4 Argon, если есть по тарифу; иначе Claude Sonnet 4.6 (код) или Gemini 3.8 Flash (короткие задачи); Sonnet в Claude Code | Antigravity или Claude Code |
| А− | Gemini (Argon или Flash): документы, карточки, данные | Antigravity или приложение Gemini |
| Г | Gemini: картинки, видео, музыка, второе мнение, видео плейтеста | приложение Gemini |
| Л | люди | — |

- Усилия max не используем: Claude дольше думает и чаще передумывает.
- В Antigravity рядом с моделью выбирается уровень мышления: Low, Medium или High. Чем выше уровень, тем лучше ответ и тем быстрее тратится лимит:

  | Модель в Antigravity | Уровень |
  |---|---|
  | Gemini 4 Argon | Medium — задачи А по образцу; High — первая задача своего рода (2.0: веб-сборка и CI) |
  | Claude Opus | High — задачи О; Medium — где в карточке «хватит medium» (2.6) |
  | Claude Sonnet 4.6, Gemini 3.8 Flash | Medium |
  | любая | Low — только короткие вопросы без правок |

  Задач О+ (усилия xhigh) в Antigravity нет — только Claude Code.
- Чат сам сверяет свою модель с меткой задачи (Sonnet подходит для А). Не совпало — скажет и даст первое сообщение для нужного инструмента.
- Модель не справилась с задачей А за один чат — задача переходит на О, а в вопрос D45 в [decisions.md](decisions.md) идёт строка: какая модель, какая задача, что не вышло.
- На AI Plus лимиты Gemini и Claude отдельные: документы на Flash и код на Sonnet можно вести параллельно. Opus — только когда Sonnet не справился.

## Настройка (один раз)

### Antigravity

1. Скачайте Antigravity с официального сайта Google и войдите тем аккаунтом Google, где подписка AI Pro или AI Plus. Модели и лимиты у тарифов разные — таблица «Инструменты».
2. Склонируйте репозиторий через GitHub Desktop и поставьте Godot 4.7.2 ([README](../README.md), «Как запустить на компьютере»). Положите Godot в `C:\Godot\` — там его найдёт `run_tests.bat` — или пропишите путь в переменной `GODOT`. После свежего клона проект надо импортировать, иначе тесты падают: `run_tests.bat` делает это сам, вручную — `godot --headless --path game --import`.
3. Добавьте папку репозитория как проект — один раз: слева рядом с Projects значок папки с плюсом → New Project → Add Folder → папка, куда GitHub Desktop склонировал репозиторий (в её корне `AGENTS.md`). Чат вне проекта не видит файлов, `AGENTS.md` и команд `/start`, `/finish`.
4. Модель агента — Gemini 4 Argon, если она есть. Нет её (AI Plus, Argon «Unavailable») — Claude Sonnet для кода, Gemini Flash для документов и коротких задач. Claude Opus — для задач О и когда Sonnet не справился за один чат.
5. Права агента, чтобы не жать «разрешить» на каждую команду: Settings → General → Global Permissions → Permission Preset; для одного проекта — Settings → Projects (по умолчанию «Inherit Global»). Пресеты: Request Review спрашивает про каждую команду; Default пускает команды в песочнице, остальные спрашивает; Auto пускает безопасные, рискованные спрашивает; Turbo снимает песочницу и пускает всё по всему диску — его не включаем: репозиторий публичный, а модели ошибаются. Поверх пресета — правила вида `command(префикс)`, приоритет Deny > Ask > Allow:
   - **Allow:** `git status`, `git log`, `git diff`, `git branch`, `git add`, `git commit`, `git checkout -b`, `git checkout main`, `git pull`, `git fetch`, `gh pr create`, `.\run_tests.bat`, Godot из `C:\Godot\`, чтение файлов;
   - **Ask:** `git push`;
   - **Deny:** `git push --force`, `git push -f`, `git reset --hard`, `git clean`, удаление файлов (`rm`, `del`, `Remove-Item`), `gh pr merge`.

   Составная команда (`cd …; …`, `&&`, `$(...)`) не совпадает с правилами по префиксу, и Allow для неё не сработает, поэтому в `AGENTS.md` правило: команды по одной, из корня репозитория, без `cd`. Всё по официальной документации Antigravity (проверка Артёма 9.11).
6. Проверка: спросите агента «Какие правила проекта ты видишь?» — он должен назвать `AGENTS.md`. Наберите `/` — в списке должны быть `/start` и `/finish`. Нет их — проверьте, что открыта сама папка репозитория (в её корне `AGENTS.md` и `.agents`), и перезапустите Antigravity. Не помогло — запасные сообщения из «Первого сообщения»: у Артёма 9.11 команд не было, запасное сработало. Папку не переименовывайте: по поисковой выдаче 9.11 официальная документация называет `.agents/workflows/`, а `.agent/` — старый путь.
7. Git: имя и почта, вход в GitHub через GitHub Desktop, чтобы агент мог пушить ветки. Чтобы агент сам открывал PR, поставьте GitHub CLI: `winget install --id GitHub.cli`, затем `gh auth login`; агент откроет PR командой `gh pr create`. Без `gh` агент только пушит: PR открывают на сайте GitHub, заголовок и описание агент даёт готовыми. Сливают PR люди: `gh pr merge` — в Deny.

**Агент пишет «Agent execution terminated due to error».** Это общая ошибка Antigravity: кончилась квота модели, модель перегружена или сбой самой программы. По порядку:

1. Retry, потом новый чат внутри проекта.
2. Другая модель в списке под полем ввода. Отвечает — дело в первой модели: вернитесь к ней позже.
3. Обновите Antigravity: на форуме Google такая ошибка уже бывала сбоем самой программы и уходила с новой версией.
4. Не помогло — кнопка Copy debug info и вопрос на форуме [discuss.ai.google.dev](https://discuss.ai.google.dev).

### Claude Code (облако)

Ничего настраивать не нужно: хук начала сессии сам печатает «Сейчас» из [progress.md](progress.md), а в облаке ставит Godot и импортирует проект. Модель и усилия выбираются в приложении: Opus, high; xhigh — только для О+.

### Приложение Gemini

Заведите три Gem (свои помощники с инструкцией и файлами), чтобы не вставлять инструкцию каждый раз:

- **«Shift Time — арт»:** лист стиля и общий фрагмент запроса (после К2), до него — запросы из [style.md](style.md).
- **«Shift Time — проверка уровней»:** правила из [concept.md](concept.md) и шаблон карточки. Задача: найти угадывание тайминга, второе новое правило на уровне, решение, которое не работает с кадра 0.
- **«Shift Time — плейтест»:** разбор видео прохождения по таймкодам: где игрок застрял, что понял неверно.

## Первое сообщение

### Antigravity

Каждый раз: слева выберите проект и начните в нём новый чат (New Conversation). Под полем ввода — модель (для 2.0 — Gemini 4 Argon) и пресет прав. Тянуть `main` в GitHub Desktop не нужно: `/start` сам делает `git checkout main` и `git pull`. Команды вроде `gh --version` — в Terminal на панели справа или в PowerShell, не в чат агента.

```text
/start
```

Нужна конкретная задача — `/start 2.1`. «Дальше» в [progress.md](progress.md) говорит, чья задача: называйте свою. Если команды нет:

```text
Это проект Shift Time. Работай по AGENTS.md и .agents/workflows/start.md. Задача 2.1. Напиши план и жди моего «ок».
```

Конец, если нет `/finish`:

```text
Заканчиваем: выполни .agents/workflows/finish.md.
```

### Claude Code

```text
Это проект Shift Time. Возьми следующую задачу с меткой О из «Дальше».
Напиши план: что увидит игрок, что решишь сам, вопросы. Жди моего «ок».
```

«Сейчас» Claude видит сам: его печатает хук. Нужна другая задача — «возьми задачу 2.3». Claude Code на Sonnet берёт и задачи А: «возьми задачу 2.1».

### Обычный чат Claude (помощник рядом с Antigravity)

Обычный чат не видит репозиторий и ничего не запускает, поэтому задачу целиком не возьмёт. Он проверяет план и код агента, объясняет падения тестов и пишет куски кода, как у Артёма на 2.9.

```text
Это проект Shift Time: 2D-головоломка-платформер на Godot 4.7.2 (GDScript со статическими типами), репозиторий github.com/ArtemPridyba/shift-time, правила — CLAUDE.md и AGENTS.md. Задачу <номер> ведёт агент Antigravity. Ты помощник: проверяешь его план и код, объясняешь падения тестов, пишешь куски кода по просьбе. Сам ничего не запускаешь. Отвечай по-русски и коротко; код и комментарии — по-английски. Вот <план агента / вывод тестов / файл>:
```

### Другие шаблоны (для обоих)

Уровень по карточке:

```text
Это проект Shift Time. Задача 3.1: собери сцену уровня и тест решения по карточке из docs/levels/. Сначала план в 3–5 строк, жди «ок».
```

Отзыв на задачу, PR которой слит:

```text
Это проект Shift Time. Отзыв на задачу <номер>:
1. <главное>
2. <остальное>
Поправь, потом тесты и PR.
```

Вопрос без изменений:

```text
Это проект Shift Time. Ничего не меняй. Объясни, как устроена запись истории.
```

Конфликт в PR («This branch has conflicts»):

```text
Это проект Shift Time. Реши конфликт в PR №<номер>: оставь изменения обеих сторон.
```

Несколько разных задач в одном сообщении — Claude Code раскладывает их навыком `razbor` (или напишите `/razbor`), Antigravity — по тому же файлу.

## Конец задачи

Напишите «заканчиваем» (Claude Code) или `/finish` (Antigravity; без команды — запасное сообщение из «Первого сообщения»). Чат:

1. запускает оба теста — они зелёные;
2. обновляет «Сейчас» в [progress.md](progress.md) и убирает себя из «Кто что делает»; пишет журнал и решения в [history.md](history.md);
3. делает коммит, пуш и PR с описанием по-русски: что изменилось и как проверить (Antigravity без `gh` даёт ссылку и готовый текст PR — вставьте его на сайте GitHub);
4. последним сообщением даёт готовое первое сообщение для следующего чата: задачу, инструмент, модель, уровень мышления и текст, который остаётся скопировать.

Слейте PR, когда проверка «Tests» внизу его страницы зелёная: Merge pull request → Confirm merge. Красная — новый чат: «почини проверку в PR №…». Сломалось после слияния — кнопка Revert на странице слитого PR вернёт всё как было. Незаконченную задачу тоже сливайте: в «Сейчас» будет передача, и следующий чат продолжит с неё.

## Как не мешать друг другу

- Перед началом — свежий `main` (в GitHub Desktop: Fetch, потом Pull); строка в «Кто что делает»; сообщение в общем чате.
- Задачи с разными файлами (поле «Файлы» в карточке). Уровни — каждый в своей сцене.
- После слияния напишите второму, чтобы он подтянул `main`. Чем дольше PR висит, тем вероятнее конфликт в `progress.md` и `history.md`.

## Голосовой ввод

Диктуйте как удобно. Claude Code применяет навык `golos`: убирает лишние слова, исправляет ошибки распознавания по словарю `.claude/skills/golos/glossary.md`, пересказывает задачу по пунктам и сверяет пересказ с оригиналом. «Ок» он спрашивает, только когда есть решение или неясность. Antigravity делает то же по `AGENTS.md`. Слово распозналось неверно — попросите добавить строку в словарь.

## Экономия

- Новый чат после PR и после часа тишины: каждый шаг перечитывает весь разговор, длинный чат дорожает.
- Opus — high; xhigh — только для О+.
- Длинное чтение (видео, большие документы, второе мнение) — в приложение Gemini; в Claude приносите короткий итог.
- Большие задачи начинайте сразу после сброса лимита, мелкие — в конце окна.
- Раз в неделю попросите любой чат Claude Code: «Запиши цену прошлых чатов» — он впишет цену в журнал [history.md](history.md).

## Отзыв

- Поиграйте 5 минут, потом напишите всё одним сообщением: сначала то, что мешает играть, потом мелочи, потом идеи.
- Просите конкретное: не «сделай загадку интереснее», а «в уровне 03 платформа должна ждать на верхней точке на секунду дольше».
- Чат пошёл не туда — остановите сразу и поправьте.
- Новая идея посреди задачи — в «Идеи на потом» в [roadmap.md](roadmap.md), а не в код.

## Плейтест

В неделе 3 дайте 2–3 людям пройти уровни без объяснений и запишите экран. Не подсказывайте, смотрите, где застряли. Запись отдайте Gem «плейтест», итог — в `docs/playtest.md`: уровень, где остановились, что поняли неверно, что сказали. Это самый ценный материал недели 4.
